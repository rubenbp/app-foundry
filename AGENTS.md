## Agent skills

### Coding standards

Antes de escribir, modificar o revisar código, lee y aplica [CODING_STANDARDS.md](CODING_STANDARDS.md).

### Issue tracker

Los issues y specs se guardan en GitHub Issues de `rubenbp/app-foundry`. Antes de crear, leer o actualizar tickets, lee `docs/agents/issue-tracker.md`.

### Triage labels

Usa los cinco roles de triage predeterminados como etiquetas de GitHub Issues. Antes de hacer triage, lee `docs/agents/triage-labels.md`.

### Domain docs

Layout single-context: `GLOSSARY.md` en la raíz y ADRs en `docs/adr/`. Antes de explorar el codebase, lee `docs/agents/domain.md`.
