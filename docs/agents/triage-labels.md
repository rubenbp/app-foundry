# Triage labels

Las skills usan cinco roles canónicos de triage. En este issue tracker de Markdown local, registra el valor correspondiente en la línea `Status:` del issue.

| Rol canónico | Status en este tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | El maintainer debe evaluar el issue. |
| `needs-info` | `needs-info` | Falta información del reporter. |
| `ready-for-agent` | `ready-for-agent` | El issue está completamente especificado y listo para un agent autónomo. |
| `ready-for-human` | `ready-for-human` | La implementación requiere intervención humana. |
| `wontfix` | `wontfix` | El issue no se llevará a cabo. |

Cuando una skill mencione un rol de triage, usa el valor de status correspondiente de esta tabla.

Para cambiar el vocabulario, edita la columna «Status en este tracker».
